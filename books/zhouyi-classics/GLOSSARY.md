# 《周易》经传与《周易正义》核心术语

> 词义按当前经传注疏语料整理；同名的后世纳甲六爻术语不得直接等同。

| 术语 | 本包中的限定用法 | 关键区别 |
|---|---|---|
| 卦 | 六爻组成的整体象与情境单位 | 不是八宫、纳甲或用神的同义词 |
| 爻 | 六个位置中的阴阳画及其爻辞，强调阶段和变动 | 不可离开全卦孤立断语 |
| 初/上/九/六 | 初、上标爻位；九、六标阳爻、阴爻并关联变爻传统 | 不等于现代编号从上往下 |
| 八卦 | 乾坤震巽坎离艮兑及其卦德、象类 | 物象是类比，不是事实指认 |
| 六十四卦 | 八卦相重形成的六画卦体系 | 每卦不是独立 Skill |
| 三才/三极 | 天、地、人三层各用两爻展开 | 属解释结构，不是科学分类 |
| 象 | 卦形、物象和类比关系的解释媒介 | 不等于因果证据 |
| 彖 | 统摄一卦材德、结构和总体义的传文 | 彖传不是卦辞本身 |
| 大象/小象 | 大象多从上下卦体推行动义；小象释具体爻 | 当前聚合《小象》有录入风险 |
| 文言 | 深释乾坤卦爻的传文 | 不能泛称所有解释文字 |
| 辞 | 系于卦爻的判断与表达文字 | 传统判断词不是统计概率 |
| 变/化 | 阴阳、爻位或情境的转化 | 不表示变卦必然覆盖本卦 |
| 通/变通 | 因变化而调整，使事情可继续 | 不是任意改释 |
| 占 | 对卦爻变化作传统判断的用途 | 只是辞、变、象、占四路之一 |
| 筮/蓍 | 以蓍草程序形成爻值的传统实践 | 程序随机属于现代实现层 |
| 吉/凶 | 得与失的传统判断等级 | 不是成功/失败概率 |
| 悔/吝 | 较轻的忧虞、追悔或小疵 | 不自动等于重大灾祸 |
| 无咎 | 经适当回应或补过而免咎 | 不等于大吉或保证无损 |
| 时 | 全卦处境及爻所处阶段 | 不等于现代日历应期 |
| 位 | 初至上及内外、尊卑等结构位置 | 不能直接人格定级 |
| 中/中正 | 二、五常谈中；中与正是结构证据 | 不是自动吉 |
| 正/当位/得位 | 阴阳居相应位置的关系 | 失位不自动凶 |
| 应 | 远位之间的对应关系 | 不等同后世六爻“应爻”的全部规则 |
| 比 | 相邻爻之间的接近关系 | 相近也可能不相得 |
| 刚/柔 | 阳/阴在作用、行为和关系上的解释语汇 | 不应固化为现代性别性格 |
| 阴/阳/道 | 相对、变化和生成关系的基本语言 | 不是经验科学测量变量 |
| 元亨利贞 | 卦辞中的四德/判断语汇，注疏解释多层 | 不能只按现代字面翻译 |
| 太极—两仪—四象—八卦 | 系辞所述生成链及注疏解释 | “四象”历来有不同解释 |
| 卦主/一为主 | 注疏用一爻统摄全卦材义的解释方式 | 不是纳甲六爻的用神 |
| 不可为典要/唯变所适 | 不把变化情境冻结成单一口诀 | 不允许无证据任意发挥 |
