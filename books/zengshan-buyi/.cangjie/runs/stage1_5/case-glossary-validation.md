# Stage 1.5 分区验证：cases + glossary

> 范围：仅验证 `candidates/cases.md` 的 `c01`–`c24` 与 `candidates/glossary.md` 的 `g01`–`g23`。  
> 方法：`task-first-v2`（V1 来源充分性、V2 可执行性、V3 任务增益）。  
> 证据边界：本报告判断的是候选是否忠实反映当前《增刪卜易》镜像中的记载，以及它对后续整理有什么用途；**不认可六爻占卜具有经现代科学验证的预测效力**。

## 1. 判定口径

1. `case` 与 `term` 按 Stage 1.5 方法通常进入 `reference`。案例本身不是可迁移的规则，术语定义本身也不是完整任务流程。
2. 只有另有完整规则明确提供适用条件、输入、步骤/分支、输出、判停与核验标准时，案例或术语才可作为该规则的证据，并由规则候选另行争取 `verified`；不能因案例“命中”或术语频次高而升级。
3. V1 通过的含义被严格限定为“可定位原文足以支持该段文本确实如此记载/定义”。对于占例，V1 **不**证明事件真实发生、叙述完整或规则有效。
4. V2 以“该 canonical 自身能否接受一组合法新输入并完成可核验任务”为准。下列案例组和术语组都不满足完整执行合同，因此均不作为 `verified`。
5. 合并只消除产品单元重复，不删除来源：每个 `source_id` 都在映射表中保留。相近条目合并后仍保留各自的来源位置与不同证据面。
6. 当前文本为转录质量有限的维基镜像，总页标记 `Textquality|25%`、分页面多为 50%；未署名段落的具体编修归属仍须校勘本/影印本复核。

## 5. 重要缺口与限制

1. **失败样本不完整**：`cases.md` 已明确只是代表性提取，并未穷尽原书占例；当前集合中成功叙述显著多于明确失败。`c09` 虽保存了“六月未中”的重要反例，仍不足以估计总体失败率。
2. **案例数量不是预测效力证据**：重复的“果”“屡验”和多个相似案例，不等于独立样本，也不能替代前瞻登记、盲态评分、对照组、基准率、完整连续样本和统计检验。
3. **结果缺乏独立核验**：多数结果来自断卦者自述；`c11` 的远期结果不完整，`c12` 的丈人病最终结果不完整，`c21` 只有来人声称地形吻合，均不可过度外推。
4. **解释自由度高**：复占、合断、占此应彼、近远切换、空破填冲和多个时间候选允许事后选择；`c09`、`c19`、`c24` 是直接风险样本。
5. **复占缺停止规则**：`g22` 与 CASE-REF-02 没有最大复占次数、固定采用标准或冲突判停，尚不能形成防确认偏误的可执行回退机制。
6. **取用与权重不唯一**：`g23` 的用神两现、`g17` 的伏神/再占冲突，以及月日动变、生克合冲之间均缺统一量化权重。
7. **版本与归属待校勘**：当前镜像总页 25%、分页面多 50% 质量标记；`c01` 明确属疑似现代录入增补，其他许多“予”叙述的具体编修层未进一步校勘。
8. **高风险禁用**：`c04/c07/c10/c18/c20` 等涉及疾病、死亡、孕产或胎儿性别，只能作为历史/批判材料；不得用于现实医疗、生育或安全决策。
9. **现代任务合同仍需外加**：原书没有医疗/法律/财务高风险分流、预注册、隐私/同意、结果核验与停止条件，这些不能从案例或术语自行补造后再归因给原书。
