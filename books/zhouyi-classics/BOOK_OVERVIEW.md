## 1. 结构（Structural）

### 类型

**复合经典 + 象征变化模型 + 占筮文本 + 伦理政治解释 + 注疏传统**。它不是一部按现代体例编写的“算命教程”，也不是纳甲六爻操作手册。

### 一句话主旨

《周易》以六十四卦及其爻位、变动和时势描述处境的形成与转化，易传和《正义》再通过象、时、位、中、应与伦理实践，把简短卦爻辞扩展为可供占筮、反思和行动审慎使用的解释体系。

### 骨架（6 个一级结构及其关系）

1. **六十四卦与三百八十四爻提供情境词汇**：每卦先给整体判断，再用六个位置表现事情从初始到终极的不同阶段；乾坤另有用九、用六。
2. **彖、象、文言解释卦德与爻位**：彖侧重统摄全卦，象以卦体/物象推导修养和行动，文言深释乾坤；同一句必须区分经文与传文。
3. **系辞建立解释与占筮理论**：讨论象、辞、变、占，说明吉凶、悔吝、刚柔、变化、蓍筮和“不可为典要，唯变所适”等方法意识（《周易》`L3522-L3661`；《正义》`L5669-L6998`）。
4. **说卦、序卦、杂卦组织映射和关系**：说卦列八卦的方位、物象、身体、家庭等类比；序卦给出卦序叙事；杂卦用对举概括卦义（《周易》`L3663-L3854`）。
5. **王弼/韩康伯以时、位、应、中正和卦主贯通义理**：不把一词固定成唯一字典义，而结合全卦结构和所处之时解释；《正义》反复提醒卦爻“义有变通”、不可拿一爻机械类推（例如 `zhouyi-zhengyi:L5751-L5777, L6835-L6867`）。
6. **孔颖达以疏解释名物、比较旧说并裁断**：既保存郑玄、马融、虞翻、庄氏等异说，也常维护王弼/韩康伯体系；因此它是唐代经学解释史的重要层，而非无立场的“标准答案”。

**结构关系**：1 是原始判断语料，2 为第一层经典解释，3 给出象—辞—变—占的方法论，4 建立八卦和卦序关系，5 提供魏晋义理引擎，6 对前述各层作唐代疏解与裁断。后世六爻只能从外部调用 1–6，不能反向篡改它们的来源归属。

### 文本要解决的核心问题

人在不确定、变化和行动风险中，如何借有限的卦象与爻辞辨认“现在是什么处境、处于哪个阶段、何种行动合时合位、哪些倾向会导致得失”，并用象征语言持续解释新的具体情境。

## 2. 解释（Interpretive）

### 关键术语（按本项目的来源分层）

| 术语 | 文本内部用法 | 容易混淆之处 |
|---|---|---|
| 卦 | 由六爻构成的整体象与情境单位；《正义》释“卦”为悬挂物象以示人 | 不是后世八宫、六亲、纳甲的同义词 |
| 爻 | 六个位置中的阴/阳画及其爻辞；“效天下之动”，强调阶段和变动 | 不能离开卦、爻位和所问情境孤立背断语 |
| 象 | 由卦形、自然物象和类比关系形成的解释媒介 | 不等于现实对象之间已被证明的因果关系 |
| 彖 | 统摄一卦材德、结构和总体义的传文 | 彖传不是卦辞本身，引用时要分层 |
| 辞 | 系于卦爻之下的文字，用来表达得失、吉凶、悔吝等 | “吉凶”是文本规范判断，不是统计概率 |
| 变 / 通 | 阴阳、爻位或情境的转化；穷则变，变则通，重在适时 | 不能机械等同于“变卦一定覆盖本卦” |
| 时 | 一卦或一爻成立的具体阶段、条件与机会结构 | 不是直接给出现代日历日期的“应期” |
| 位 | 初至上六个位置及其内外、尊卑、中不中等关系 | 位义是古代注疏模型，不能直接人格化或阶级化 |
| 中 / 正 | 二、五常见“中”；阴阳居相应爻位常谈“正”，但实际判断仍看全局 | 中正不是自动吉，失位也不是自动凶 |
| 应 / 比 | 非相邻对应爻或相邻爻之间的结构关系，用来解释相求、相得或冲突 | 不等于后世六爻的“应爻”全部用法 |
| 吉、凶、悔、吝、无咎 | 得失与风险程度的分层判断；《正义》明确有些卦爻不写吉凶是因文义已见或结果未定 | “无咎”不是“大吉”，常表示通过条件或补过避免过失 |
| 三才 / 三极 | 天、地、人三层在六爻中的成对展开 | 属解释结构，不是自然科学分类 |
| 八卦 | 乾坤震巽坎离艮兑及其德、象、方位等映射 | 说卦映射不能无边界地套到疾病、人格或犯罪结论 |
| 筮 | 以蓍草等程序形成爻值、决疑的传统实践；《系辞》详述大衍与十八变 | 程序随机起卦是现代替代实现，必须记录算法和随机种子/承诺 |

### 核心命题（用自己的话重述）

1. 卦提供整体处境，爻提供处境内部的阶段差异；解释不能只报卦名。
2. 爻辞的意义依赖“时、位、应、比、中正”及全卦关系，不是固定关键词匹配。
3. 象是把抽象结构连接到具体经验的类比工具；类比应受到上下文和来源层约束。
4. 吉凶、悔吝、无咎呈现不同强度和条件；很多爻辞保留“怎样做才趋于何种结果”的条件性。
5. 易道强调变化和适时，“不可为典要，唯变所适”反对把活的情境压成一条僵硬口诀。
6. 经文、传文、王韩注、孔疏可以相互解释，也可能存在不同侧重；输出必须允许并列而不是强行合成唯一古意。
7. 《系辞》确实把占筮列为《易》的用途之一，但同时列出辞、变、象、占四类用法；不能把整部《周易》缩减为预测术。
8. 《正义》以自然秩序类比君臣、夫妇、尊卑，反映其时代政治伦理；现代使用不能把这种类比当作性别或权力关系的正当化。
9. “十年”“七日”“八月”等数字首先要在具体卦爻和注疏语境中解释，不得直接生成确定日期。
10. 原典义理可以辅助六爻解释：先完成本卦、动爻、变卦的技术计算，再查相应经传注疏；它不提供纳甲、月日旺衰和六亲取用算法。

### 论证与解释链

1. **确定文本对象**：记录本卦、动爻、之卦和所问期限；不清楚爻位时不进入义理解读。
2. **先读经**：查卦辞与相关动爻爻辞，保留原文，不先用现代话替换。
3. **再读传**：用彖看全卦主旨，用象看整体行动取向，用小象理解具体爻位；乾坤再查文言。
4. **补方法背景**：必要时查系辞的象、辞、变、占与时位思想，查说卦的八卦物象，但限制类比范围。
5. **查注疏**：分列王弼/韩康伯注和孔颖达疏，记录他们如何使用中、正、应、比、时、位以及引用的异说。
6. **生成双层输出**：一层是“传统文本内部怎么解释”，另一层是“对现实可采用的反思问题/行动选项”；不得从第一层跳成事实预测。
7. **与六爻会合**：现有六爻 Skill 提供装卦、用神、旺衰、动变证据账本；本包只为本卦、动爻和之卦提供经传注疏解释及冲突审计。
8. **风险回退**：健康、法律、投资、人身安全等问题只给文化解释和现实核验清单，转交专业判断，不以卦辞决定行动。

## 3. 批判（Critical）★

### 时代局限

- 《正义》的解释大量使用君臣、尊卑、夫妇、嫡庶、刑罚和王道政治结构；这些是前现代社会语境，不能直接作为现代关系伦理。
- 阴阳经常被类比为男/女、尊/卑、先唱/后和；把这些解释用于现代亲密关系，容易固化性别和权力不平等。
- 自然物象与人事之间多通过类比而不是可检验因果连接；类比可以启发反思，但不能证明事件会发生。
- 占筮段落声称可以知来、断疑，这是文本内部信念；本项目没有发现能证明其超常预测效力的现代实验材料。

### 注疏立场与版本盲点

- 《周易正义》总说明本身承认其总体上尊王弼、排斥或压低其他易学；孔疏保存异说的同时并非中立汇编。
- 王弼义理化解释重视“一”、卦主、时位与无为，可能弱化更早象数、筮法或训诂传统；不能把王注等同于唯一古义。
- 当前中文维基文库镜像转录质量有限：《小象》聚合页有错字，《正义》有两份“随”页；引文必须保留页名和校核状态。
- 传统作者题署不能替代现代文本学研究；在没有可靠版本学资料时，作者与年代应标“传统归属/待核”。

### 未被证明的假设

- 随机或蓍草生成的卦与现实问题之间存在超越偶然、可重复验证的对应关系。
- 象、时、位的解释能唯一映射到现实人物与事件，而不是依赖解释者事后选择。
- 经传注疏中的吉凶判断可以直接推出未来结果、具体时间或他人内心。
- 重复起卦能增加真值而非扩大选择性解释和确认偏误。
- 古代社会秩序类比具有跨时代的规范有效性。

### 最强反对意见

六十四卦、三百八十四爻、众多物象、多个注家与高度可变的时位解释提供了极大的叙事自由度；若不预先固定问题、起卦算法、采用哪一层文本、判定标准和截止时间，几乎任何结果都能事后找到相符语句。因此它可以是有价值的文化文本和结构化反思工具，却不能仅凭“解释得通”证明预测准确。

### 现代应用边界

- 可做：原典学习、卦爻辞查找、来源分层、注疏比较、反思提问、六爻结果的文化解释。
- 需标注：所有预测性结论均为传统术数内部推演；时间、对象特征和结果必须用概率/条件语言，不能承诺。
- 不可做：依据卦象诊断疾病、停药、决定投资/借贷、判断犯罪或忠奸、替代法律意见、决定人身安全或生育事项。
- 起卦纪律：同一问题在没有实质新信息前不反复起卦；若复问，记录原因并保留前一次结果，防止挑选顺眼答案。

## 4. 应用潜力（Applicability）

### 可 skill 化的候选内容

- [ ] **卦爻原典定位器**：按卦、爻、层级返回经/彖/象/文言/注/疏的准确文本与位置。
- [ ] **来源分层与归属审计器**：防止把传、注、疏、现代解释或后世六爻说成“经文原话”。
- [ ] **本卦—动爻—之卦义理辅助器**：先整体、再动爻、后变化方向，输出分层解释而非一句吉凶。
- [ ] **时—位—中—应—比结构分析器**：解释注疏如何从爻位与关系得出判断，并显示反例和条件。
- [ ] **八卦取象限制器**：查询说卦物象，同时阻止无限联想、字面化医疗判断和人格定性。
- [ ] **经传注疏冲突矩阵**：并列王韩注、孔疏所存异说与现代未决点，不伪造唯一答案。
- [ ] **引文与版本核验器**：检测错页、重复“随”页、聚合页录入错误和未经核对的流行语录。
- [ ] **六爻桥接器**：接收现有六爻 Skill 已算出的本卦、动爻、变卦，只补经典义理，不重新计算纳甲。
- [ ] **高风险停机与现实核验器**：将医疗、法律、财务、安全问题转成现实证据和专业求助清单。

### 不适合独立 skill 化或不得 active 化的内容

- 不把每一卦拆成 64 个独立 Skill；它们应是同一来源路由下的资料与能力参数。
- 不分别创建“周易 Skill”和“易经 Skill”；两名称通常指向同一核心典籍，拆开会重复、抢触发。
- 不把王弼、韩康伯、孔颖达各做一个默认入口；保留为一个查询中的来源层。
- 不把《说卦》的身体、动物、家庭、方位映射直接做成疾病诊断、人物画像或寻物定位器。
- 不将“河图洛书”“八宫”“分宫卦序”或后世纳甲内容无来源地混入经传层。
- 不把具体感情、财富、疾病占例当成原典已经证明的现实预测规则。

### 预估能力数量

**约 7–9 个内部能力单元，最终 1 个可发现入口。** 推荐与现有 `traditional-divination-skill`、`zengshan-buyi` 通过路由组合，而不是再造多个相互冲突的算命 Agent。
