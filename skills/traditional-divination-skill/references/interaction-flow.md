# 交互流程

## 1. 规范问题

优先得到：具体事项、相关对象、时间范围。用户说“看看感情”时，可建议改为“未来三个月，我在建立或推进稳定关系方面最需要注意什么？”；若用户已有对象，则保留该对象，不擅自改成新恋情。

一次只追问真正必要的信息。用户不愿提供背景时仍可起卦，但要说明解释会更宽泛。

## 2. 获取六爻

用户自行摇卦时，明确顺序为“初爻到上爻（从下往上）”，每次三枚硬币：正面记 3、反面记 2，总和只能是 6、7、8、9。

用户授权随机时，在 Skill 根目录运行：

```powershell
python scripts/cast_coins.py
```

只运行一次。随后把输出中的 `lines` 原样传给：

```powershell
python scripts/derive_hexagram.py 7 8 8 8 8 8
```

把示例数值替换为实际六爻。原始结果必须随回答展示，便于复核。

若需要纳甲分析，还必须记录实际投完卦的当地日期时间与 IANA 时区，例如 `2026-09-17T15:42:00`、`Australia/Sydney`。随后运行：

```powershell
python scripts/derive_liuyao_chart.py 7 8 8 8 8 8 --cast-time 2026-09-17T15:42:00 --timezone Australia/Sydney --category 考试 --question "具体问题"
```

脚本会按该日期自动处理时区偏移和夏令时。若时间未知，只做卦象层解释，不拿当前时间补盘。

## 3. 异常处理

- 少于或多于六爻：停止并请用户重列，不能补齐。
- 顺序不明：只确认顺序，不猜。
- 出现 6/7/8/9 以外的值：解释计分法并重新收集。
- 起卦时间或时区未知：保留卦象计算，停止月建、日辰、旬空和完整纳甲分析。
- 重复问同一件事：提示重复起卦容易放大焦虑；优先核对现实中新出现的信息。
