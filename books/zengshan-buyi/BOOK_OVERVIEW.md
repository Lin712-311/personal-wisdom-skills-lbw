## 1. 结构（Structural）

### 类型

以六爻纳甲为核心的**实操规则手册 + 占例集 + 旧说批判/校订集**。它既教装卦、取用和判断，也以大量回顾性案例为规则辩护，并在不同生活领域给出分门断法。

### 一句话主旨

本书试图用“明确所问—装卦取用—审月日旺衰与动变生克—按事类和应期判断—疑义时分占或复占”的体系，取代作者认为拘泥卦名、神煞和固定口诀的旧式断法。

### 骨架（5 个一级结构及其关系）

1. **占前立题与入门建模**：要求“一念一事”、明确是谁占什么，并介绍八卦、六十四卦、纳甲、六亲、世应、动变等表示系统（序及卷一章 1–7）。
2. **核心推理引擎**：按问题选“用神”，再区分元神、忌神、仇神，结合月建、日辰、四时旺衰、生克、冲合、刑、空、破、墓、绝、进退、飞伏、反伏等判断强弱和方向（卷一章 8–26 及附加总注）。
3. **校订旧说的方法论**：反复以“屡试”“不验则删”“不可拘执”“分占”“卦不明再占”反驳旧书规则，强调用神、旺衰、动变优先于卦名、六神和星煞（序、卷二章 27–35及全书评议）。
4. **领域化决策分支**：把通用引擎应用到天时、身命、功名、考试、仕途、求财、婚姻、生育、出行、诉讼、疾病、家宅与坟墓等具体门类（卷二章 35；卷三章 36–68；卷四章 69–130）。
5. **应期与复核**：通过逢值、逢冲、逢合、填实、冲墓、旺衰转换等生成时间判断；若卦意含混，则主张分拆问题、复占或由相关者另占，并把多个结果合断（卷一应期总注与散见案例）。

**论点之间的关系**：1 提供输入与符号；2 提供通用推理规则；3 规定如何选择、删改和复核规则；4 将 2 的规则按任务情境展开；5 为所有情境补充时间输出与不确定时的回退路径，整体是“输入 → 建模 → 推理 → 领域分支 → 应期/复核”的递进结构。

### 作者要解决的核心问题

如何让学习者在面对具体疑问时，能从六爻卦中选择与问题对应的变量，处理相互冲突的强弱与动变信号，给出吉凶、成败、来去及应期判断，同时避免照搬作者认为未经占例检验的旧诀。

## 2. 解释（Interpretive）

### 关键术语（按文本内部用法）

| 术语 | 书中用法 | 与常识用法的差异 |
|---|---|---|
| 用神 / 主事爻 | 针对当前问题选出的核心爻；自占多取世爻，占六亲、财、官等按类别取相应六亲爻 | 不是宗教意义的“神”，而是内部模型中的目标变量 |
| 世爻 / 应爻 | 世多代表占者或己方，应多代表对方、他人、目的地或医生等；具体含义随问题改变 | 不是固定人物标签，取义依赖问题合同 |
| 六亲 | 父母、兄弟、妻财、官鬼、子孙五类关系，也是文书、财物、忧患、医药等事物的类目映射 | 超出亲属关系，承担广泛的象征变量角色 |
| 元神 | 生扶用神的爻 | 不是精神实体，而是用神的支持因素 |
| 忌神 | 克害用神的爻 | 不是普遍禁忌，而是相对于当前用神定义的阻碍因素 |
| 仇神 | 克元神并生忌神的爻 | 是二阶不利因素，不等于日常所说的仇人 |
| 旺相 / 休囚 | 依据月、日、季节及生扶等判断爻是否“有力” | 是术数系统内部的情境强弱，不是可直接测量的物理量 |
| 旬空 / 月破 | 某地支在旬内缺位或被月建相冲；书中强调空破可因发动、填实、冲空等而改变效力 | 不是实际不存在或损坏，而是时态化的内部状态 |
| 动爻 / 变爻 | 掷卦中的老阴老阳为动，动后得到变爻；变爻主要回头作用于本位动爻 | “动”“变”是形式运算，不是现实对象真的运动 |
| 进神 / 退神 | 特定地支序列的动变，象征趋势推进或退减；仍须结合旺衰、空破和时间 | 不是一般语言中的进退，而是限定的地支转换 |
| 飞神 / 伏神 | 用神不上卦时，从本宫首卦寻找伏神；覆盖它的本卦之爻为飞神 | 是排卦结构中的显隐关系 |
| 六合 / 六冲 / 三合局 | 地支或卦的合、冲、成局关系，用来表达聚散、牵绊、冲开或同向作用 | 不是现实中的契约或冲突，且吉凶必须附着用神与强弱判断 |
| 反吟 / 伏吟 | 卦爻变化形成反复相冲或地支不变，书中多解释为反复、不宁、滞留 | 属卦变型态，不等于心理学意义的反刍或吟诵 |
| 应期 | 预测规则被认为会显现的年、月、日、时，按动静、空破、合冲、墓绝等选取 | 不是经统计估计的置信区间，而是术数时间映射 |
| 分占 / 多占 | 将一个复合问题拆为一事一问；卦象含混时再次起卦并合看 | 类似问题分解与复核，但书中也允许高自由度的事后解释 |

### 核心命题（用自己的话重述）

1. 先把问题、占者、对象和时间范围说清，否则同一爻无法稳定取义。
2. 一卦不应同时承载多个独立问题；父母、功名、财利、安危等应尽量分占。
3. 判断应以当前任务的用神为中心，不应仅凭卦名、六神、神煞或固定位置下结论。
4. 月建、日辰、动爻和本位变爻构成四类主要作用来源；应比较生扶与刑冲克害的整体强弱。
5. “动”是重要信息，但动爻并非机械地吉或凶；必须看它对用神、元神、忌神的关系以及自身旺衰。
6. 空、破、墓、绝不是一律无用或必凶；要看有无根气、动静、生扶及以后何时冲开或填实。
7. 用神的情境强弱比表面吉象更重要；表面有元神相生，而用神“无根”时，书中仍判生扶无效。
8. 六合、六冲、反吟、伏吟等只能作为附加结构，不能脱离用神机械决定结果。
9. 若规则冲突或卦意含混，可以复占、让相关人分别占，或把复合问题拆开后分别判断。
10. 旧书规则应以作者积累的占例检验；屡试不验者删，单有偶合者不应立为通则。
11. 领域判断仍复用同一套核心引擎，但不同任务的用神、喜忌和完成标准不同，不能跨题套用。
12. 预测结果若被认为可趋避，书中鼓励采取行动；同时也在“行险求财”“偷葬”等章节拒绝为不义行为提供术数指导。

### 论证链

1. **立题**：先确定“谁、为谁、问什么、问到何时”，并主张一事一问；问题不清会导致取用不同（例如流年、功名、疾病、归期各有不同用神）。
2. **形式化**：由六次掷钱得到本卦、动爻与变卦，装纳甲、六亲、世应和六神。卷一分页面给出完整装卦说明，但其中 `L4602-L4692` 明确属于录入者疑似增补。
3. **选目标变量**：依问题确定用神，同时标出元神、忌神和仇神；用神两现时再按动静、强弱、空破等选择。
4. **聚合证据**：分别检查月建、日辰、动爻、变爻，以及空破墓绝、合冲刑、进退、飞伏等；核心判断是“谁对用神有力、谁受制、何时状态改变”。
5. **领域解释**：把内部关系翻译成成败、安危、往来、得失等结论；再按事类章节加入专属规则。
6. **应期推导**：根据静逢值/冲、动逢值/合、空待填/冲、墓待冲开、衰待生旺等生成候选时间点。
7. **疑义回退**：卦不明时复占或分占，并以多个卦相合来增强确信。
8. **案例背书与删改**：作者用个人多年占例、旧书对比和“验/不验”记录支持规则，李文辉与李我平再作删订、评论或赞评。

**证据性质**：书内证据主要是回顾性个案、个人记忆、传闻与命中案例。它展示了作者如何建立内部一致性，却没有前瞻登记、盲法、对照组、完整失败样本、基准率或统计检验，因此不能证明六爻具有超出偶然和解释弹性的预测能力。

## 3. 批判（Critical）★

### 时代局限

- 大量任务依赖科举、候补、援例、面圣、品级、宗法继嗣、纳妾、童养、生男生女、旧式刑罚与官衙等制度背景；即使忠实还原，其现实任务接口也大多已经消失。
- 婚姻、生育和家庭章节明显采取男性家长制视角，把女性、妾婢、子嗣和“财”作类比；这些价值预设不适合直接移植到现代关系决策。
- 疾病章节虽有“生病应找医生”等现代录入者说明，也有古籍中反对滥祭鬼神、承认服药求医的段落，但仍把病因、药效、生死和医者选择系于卦象；这不符合现代循证医学与医疗伦理。
- 文本有明显数字化和传抄风险：总页标记 Textquality 25%，分页面多为 50%，且可见错字、异体、重复页、现代按语和疑似录入增补，不能把当前镜像视为经过严格校勘的定本。

### 作者与增删者的立场盲点

- 他们具有强烈的术数实践者立场：即使主动删除不验旧诀，也预设“卦必有意义、神会回应”，未把“没有预测能力”作为可被检验的竞争假设。
- 占例多由断卦者叙述，缺少完整样本、失败记录和独立核验；“灵机变通”与“占此应彼”给了事后改释极大空间。
- 对社会等级、性别、残障、贫富和职业的评价带有明显时代偏见，例如把某些卦象与“鄙俗”“下贱”“愚痴”等人格判断相连。
- 虽反对部分伤害性祭祀、赌博、偷葬和不义求财，但仍把灾祸、疾病、死亡与鬼神、阴德、风水联系，可能造成污名、恐惧和延误专业帮助。

### 未被证明的假设

- 随机起卦能与现实事件产生可重复、可区分偶然的对应关系。
- “诚心”“一念”会提高准确性，而模糊或失败可以用心不诚、问题不专、占近应远、占此应彼解释。
- 少量或精选的占例足以建立普遍规则，且未记录的失败不会改变结论。
- 多次复占能澄清而不是放大确认偏误和选择性采纳。
- 五行、六亲、六神、地支合冲等象征映射能对健康、死亡、犯罪、胎儿性别、天气和市场结果给出因果或预测信息。
- 结果改变可归因于“趋避”，而不是普通行动、自然变化、基准率或叙事重构。

### 最强反对意见

该体系拥有大量可变的取用规则、例外、时间窗口、象征映射和复占机会，几乎任何结果都能在事后找到解释；在没有预注册问题与判据、连续完整样本、盲态评分、对照基线和独立复现的情况下，书中“百试百灵”式结论更可能来自选择性报告、确认偏误、回忆偏差、基准率忽视和解释自由度，而不是被证明的预测机制。

### 可保留的方法论价值与边界

- 可保留：问题拆解、明确输入合同、变量映射表、证据冲突记录、例外审计、来源归属、拒绝在证据不足时假装有方法。
- 只能作为历史系统重建：装卦、用神、旺衰、应期等规则可以被形式化和测试，但输出必须标注“传统术数内部推演”，不能包装成事实预测。
- 禁止替代专业判断：医疗、法律、财务、犯罪风险、生育、死亡等高风险决策不得以卦象作为诊断、建议或行动依据。

## 4. 应用潜力（Applicability）

### 可 skill 化的候选内容

- [ ] **问题合同与分占器**：把“谁问、为谁问、问什么、时间范围、是否混合多个目标”整理为单一可检查任务；这一部分可独立于占卜真伪使用。
- [ ] **来源分层与文本归属审计**：识别野鶴、觉子、李我平、原剑、录入者和维基镜像层，防止现代补料被误归为古籍。
- [ ] **传统六爻装卦工作表**：把六次结果转换为本卦、动爻、变卦、纳甲、六亲、世应；仅用于历史学习/文本复现，并显示来源版本。
- [ ] **用神—元神—忌神—仇神映射器**：按指定问题生成候选变量和映射依据；对歧义给出分支而不是硬选。
- [ ] **内部规则证据账本**：逐项记录月日、动变、生克、空破墓绝、合冲刑、进退飞伏等支持/反对信号及原文出处，不直接宣称现实预测有效。
- [ ] **规则冲突与例外审计器**：把旧诀、野鶴修订、觉子增删、李我平评议、占例和反例并列，识别循环解释、事后改释和未定义权重。
- [ ] **应期规则计算器（研究模式）**：按书内规则列候选年/月/日/时及推导链，用于可复现性研究；不得输出“必然发生”。
- [ ] **占例结构化与前瞻检验模板**：将问题、起卦前判据、预先承诺的结论、截止时间、实际结果和失败样本完整登记，用于检验书中主张，而不是只收命中例。

### 不适合 skill 化或不得作为 active 能力的内容

- 以卦象预测、诊断或处置疾病、生死、胎儿性别、刑事责任、诉讼结果、灾害、投资收益和他人忠奸。
- 按鬼神、风水、祭送、阴德或“冤家债主”解释疾病与灾祸；任何可能延误医疗、法律或安全处置的做法。
- 依性别、阶层、残障、职业或婚育状况给人作道德与人格定性。
