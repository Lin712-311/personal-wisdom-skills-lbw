- `canonical_id` 是本分区合并后的规范项；反例若只是某框架的负向表述，就并入该规范项，保留全部来源 ID 和位置。

## 5. 重要缺口与阶段结论

1. **端到端排盘缺口**：本分区只有投掷编码完整通过；纳甲、六亲、世应的全字段工作表需要从其他候选分区或原文另作验证，不能由 FW-002 标题外推。
2. **三处关键冲突未解**：用神多现（CAN-12）、伏神与复占（CAN-13）、复占停止（CAN-14）均不能在现有来源下生成唯一、可检验的决定。
3. **规则聚合无统一权重**：四源账本可复现，但当旺衰、空破、动变、合冲和专章例外互相冲突时，原书仍依赖“灵机变通”。CAN-04 因此不能通过完整流水线验证。
4. **证据有效性边界**：书内“屡验”“果然”是回顾性个案和作者自述，缺连续样本、失败分母、盲法、基准率、预注册及独立复现；所有传统规则的 `verified` 均不等于现实预测有效。
5. **安全与伦理只作 reference**：现代录入层的“生病找医生”和 Stage 0 高风险禁用原则方向正确，但不足以替代地区化专业规范；古籍反对机械卜药不等于反对用卦决定医疗，二者不可混同。
6. **版本真实性缺口**：当前拼接镜像明确自称未仔细校对，且含现代按语、疑似录入增补和低 Textquality 标记。没有校勘本前，只能做当前文本的可追溯重建。

本分区已逐项覆盖 17 + 19 个候选及 ZSBY-T01–T09，但仍是**部分完成的 Stage 1.5 验证**：12 个 canonical 方法可进入后续 Stage 1.6 评估，5 个只作参考，4 个需补审；本报告未创建 `verified.md`、`references.md`、`needs-review.md`、`rejected/` 或任何能力卡。
