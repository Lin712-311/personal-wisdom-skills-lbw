# 输出格式

## 占问信息

- 原问题与规范后的问题
- 时间范围
- 起卦方式与时间

## 可复核卦象

- 从初爻到上爻的六次结果
- 本卦（编号、名称、上下卦）
- 动爻
- 变卦（编号、名称、上下卦）
- 纳甲分析启用时另列：当地起卦时间、IANA 时区、干支、月建、日辰、旬空、卦宫、世应、六亲、六神和用神口径

## 分层解释

清楚区分三层：

1. **排盘事实**：脚本计算出的卦、干支、纳甲、世应、六亲、六神和状态标记；列出引擎版本。
2. **已验证规则**：只有能定位到已审计来源的规则才可放这里。
3. **一般文化解释**：基于卦名、变化和传统象征的启发式阅读，不冒充完整六爻断法。
4. **当前推断**：结合用户背景形成的条件性假设，写明什么事实会使它失效。

用神两现、伏神、规则冲突或应期缺乏稳定仲裁时，明确标 `unresolved`，不得把引擎字段强行合成为唯一结论。

## 现实建议

给出 2–4 个低风险、可验证的行动，例如澄清沟通、设定观察期限、收集事实或咨询合格专业人士。说明哪些结果可以用来回看判断，而不是要求用户盲从。

## 不确定性

用一句清楚的话说明：这是传统文化解释，不是经科学验证的预测，不能保证事件发生。
