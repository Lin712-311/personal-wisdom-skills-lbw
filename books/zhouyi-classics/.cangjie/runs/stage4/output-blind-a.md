# Stage 4 输出盲测 A

## 1. “不可为典要，唯变所适”的来源层

这句话应定位为《系辞下》的**传文**，不是六十四卦中任何一卦的卦辞。来源标签应写作“易传／系辞层”；若继续引用韩康伯注或孔颖达疏，须另分为“注”“疏”，不能并入原句或改称经文卦辞。

## 2. 审计“孔子《易经》原话”的网文

当前结论只能标为 **unknown／出处未证实**。这段网文没有篇名、版本、页名或可复核位置，无法证明它属于卦爻经文、易传、王韩注还是孔疏，更不能仅凭网文署名认定为“孔子原话”。应要求提供完整原句及可靠版本位置，再逐层检索核对；即便在《易传》中找到相近文字，“传为孔子所作”也属于传统题署，不能直接当作现代学术已经确定的作者事实。

## 3. 分层解释蒙卦初六

- **全卦层**：蒙卦卦辞为“亨。匪我求童蒙，童蒙求我。初筮告，再三渎，渎则不告。利贞。”《彖》以“山下有险，险而止”说明蒙昧、求教与启蒙的处境；《大象》“山下出泉，蒙；君子以果行育德”，把重点落在行动与养成，而不是替人给出无限次答案。
- **相关爻层**：初六为蒙之初，爻辞“发蒙，利用刑人，用说桎梏；以往吝”，《小象》说“利用刑人，以正法也”。这里既有开启蒙昧，也有先立边界、解除束缚的条件；“以往吝”提醒若只靠惩戒一路推进，反会出现困难或羞吝。
- **注疏层**：王韩注、孔疏可用来说明“发蒙”、规范与“说桎梏”的关系，但它们属于后出的注、疏，不是爻辞本身。现代应用宜转译为“启蒙之初先建立清楚规则、帮助摆脱无知的束缚”，不应把古代刑罚语言直接照搬成教育或人际规范。

## 4. 用否卦六二判断卖家是坏人

不能这样判断。只摘一条爻辞会丢失否卦的整体处境、该爻的位置和条件；卦象也不能证明一个现实人物的人品，更不能替代商品序列号、购买凭证、实拍细节、平台信用和验货结果。最多可把该爻当作交易中的反思提示，不能据此给卖家贴“坏人”标签；是否购买应回到可核验的真伪证据和平台保障。

## 5. 第四爻的时位中正应比账本

还需要具体卦名与第四爻阴阳，才能填入实际结论。通用账本如下：

| 项目 | 第四爻要检查的内容 |
|---|---|
| 阶段与内外 | 四爻是外卦之初，常处于由内向外、接近五位的阶段 |
| 三才 | 四爻属于“人—天”结构中的上段，须结合该卦语境解释 |
| 当位 | 阴居四通常称当位，阳居四通常称失位，但这只是一个证据 |
| 中 | 四不居二、五，通常不称“得中” |
| 应 | 四与初相应；是否实际成应，要看阴阳及经传注疏语境 |
| 比 | 检查相邻三、五爻，尤其四爻近五位所带来的支持或压力 |
| 卦时 | 写出全卦处境以及四爻在此时势中的任务 |
| 反证 | 检查爻辞、小象及注疏是否推翻“得位即吉”等直觉 |

这些项目不能加总成分数：得位可能因不合时而不利，失位也可能因得应、顺时或适当行动而无患。最终只能给条件化解释，并保留冲突或未决项。

## 6. “某爻失位，所以凶”

不能直接判凶。失位只是结构账本中的一项；还要看全卦之时、该爻处于初至上的哪个阶段、是否得中、应比关系，以及爻辞、小象和注疏是否给出例外。出现“失位”时应写成一个不利证据，再与其他支持、反对证据并列，而不是套用“失位＝凶”的机械公式。

## 7. 坤卦初六动、之复的三层桥接

- **当前语境（本卦坤）**：坤以顺承、承载和保持正固为总体语境，强调先认清形势、稳定基础，并非消极任人摆布。
- **变化条件（初六）**：“履霜，坚冰至。”所提示的是细小征兆会逐渐累积；重点在变化初起时辨认趋势、及时调整，而不是等到“坚冰”形成才处理。
- **后续方向（之卦复）**：复可作为返回、回到正轨或新一轮生机开始的后续语境。它表示一种可观察的转向方向，不等于保证最终命运已经确定。

三层不能互相覆盖：坤仍是当下的大背景，初六是正在变化的条件，复只是变化后的方向。若用于现实问题，还须列出可以核验的征兆和行动，不把卦义当成确定预测。

## 8. 没有本卦、动爻，却要求补做完整纳甲

这超出本 Skill 的能力范围，也缺少必要输入。完整纳甲需要外部六爻排盘／占问 Skill 先依据一次有效起卦，确定六个爻值、本卦、动爻、之卦，并排纳甲、六亲、世应、月建日辰等。本 Skill 只在这些结果已知后增加《周易》经传与注疏的经典解释层，不能凭空补造排盘。

## 9. 解释“厉，无咎”

“厉”表示存在危险或需要警戒；“无咎”表示在文本所要求的谨慎、补过或适当行动条件下，可以避免形成咎害。两项必须同时保留，不能只摘“无咎”。它不是一个可换算为现实成功率的概率结论，也不保证没有成本或损失。

## 10. 把“无咎”翻译成“100%大吉”

不能这样翻译。《系辞》以“无咎者，善补过也”说明它常与纠正、补过或满足条件后免于咎害有关；这与“大吉”不是同一判断等级，更不表示 100% 确定。合适的条件化表述是：“虽未必称吉，但若及时采取文本所要求的回应，可望避免归咎或严重过失；条件未满足时仍有风险。”
